# Changelog

## 0.1.0-8 - 2026-09-04

1. Added GitHub, BigWigs packager, and CurseForge-ready release metadata.
2. Added repository-safe verification, packaging, deployment, and version publishing workflows.
3. Expanded project documentation for installation, configuration, development, and releases.

## 0.1.0-7 - 2026-09-04

1. Moved Preview Frames and Lock Frames to the top row of Frame Options.

## 0.1.0-6 - 2026-09-04

1. Added shared 0%, 25%, 50%, 75%, and 100% encounter-frame background opacity choices.
2. Removed the drag-status text from the Room Map and Wind Drop Order headers.

## 0.1.0-5 - 2026-09-04

1. Reorganized Configuration options into a clean two-column grid.
2. Added Preview Frames and Lock Frames toggles.
3. Preview uses the configured marker layout and frame visibility settings.

## 0.1.0-4 - 2026-09-04

1. Added `/sh` as a shortcut for all `/sszorak` commands.
2. Made `/sszorak test` and `/sh test` toggle Test Mode on and off.
3. Added a draggable minimap button that opens Configuration.

## 0.1.0-3 - 2026-09-04

1. Test Mode now starts with empty assignments and populates the drop-order frame from map selections.
2. Added independent scale controls for the Room Mini Map and Wind Drop Order Frame.

## 0.1.0-2 - 2026-09-04

1. Added a close button to the upper-right corner of Configuration.

## 0.1.0-1 - 2026-09-04

1. Fixed WoW's Lua parser rejecting the movable-frame drag handle syntax.

## 0.1.0-0 - 2026-09-04

1. Added the movable eight-position Sszorak room map with synchronized wind-order buttons.
2. Added automatic opposite-side drop assignments and a four-marker wind drop order frame.
3. Added NorthernSkyRaidTools-compatible raid-chat publishing and external order detection.
4. Added encounter-timeline Surge warnings, intermission push warnings, map rotation, and phase resets.
5. Added account-wide frame, warning, difficulty, and marker-layout configuration.
6. Added reload-safe temporary raid layouts with Reject, Temporary, and Make Default choices.
7. Added local test controls for both Surges, the full intermission, phase reset, and frame positioning.
